# Домашка JS 12 — слайдер

Слайдер з практики, переписаний двома способами:

- `prototype/` — на прототипах (`function Slider` + `Slider.prototype`)
- `class/` — на класах (`class Slider`), з паузою при наведенні миші

Щоб запустити, відкрийте `index.html` у потрібній папці.

## Як влаштовано

- `Slider` — базовий слайдер: слайди, точки, кнопки, автопрогортання, стрілки на клавіатурі.
- `SwipeSlider` — наслідує `Slider` і додає свайп пальцем і перетягування мишею.

В HTML є лише `<div class="slider"></div>`, а все інше створює JavaScript.

## Налаштування

Слайдер налаштовується об'єктом `config` на початку `main.js`:

| Поле           | Що означає |
|----------------|------------|
| `selector`     | Контейнер, у якому буде слайдер. |
| `slides`       | Масив посилань на картинки. |
| `interval`     | Інтервал автопрогортання в мілісекундах. |
| `autoplay`     | `true`: автопрогортання вмикається одразу. |
| `showDots`     | `true`: показувати точки. |
| `showButtons`  | `true`: показувати кнопки Назад / Вперед / Пауза. |
| `swipeDistance`| Скільки пікселів треба протягнути пальцем або мишею, щоб слайд перемкнувся. |
| `pauseOnHover` | `true`: зупиняти автопрогортання, коли миша над слайдером (тільки версія з класами). |
